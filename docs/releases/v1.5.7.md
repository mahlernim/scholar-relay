# ScholarRelay v1.5.7

## English

- Open an alphaXiv reader or abstract page to import the paper PDF into Gemini Notebook. A link to a specific revision imports that revision.
- Select papers from an alphaXiv feed. Multiple links to the same revision appear as one choice.

## 한국어

- alphaXiv 논문 뷰어나 초록 페이지에서 논문 PDF를 Gemini Notebook으로 가져올 수 있습니다. 특정 버전의 링크를 열면 해당 버전을 가져옵니다.
- alphaXiv 피드에서 가져올 논문을 선택할 수 있습니다. 같은 버전으로 연결되는 여러 링크는 한 항목으로 표시됩니다.
