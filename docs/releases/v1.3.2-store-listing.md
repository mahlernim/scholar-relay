## English

ScholarRelay (Scholar Relay) imports PDFs, arXiv research papers, and webpages into Gemini Notebook, formerly NotebookLM. Organize your notebook and generate Audio Overviews and study materials in one workflow.

- Import a PDF from the current page or a local file. Paper titles come from HTML metadata or bounded local PDF metadata checks, with a useful filename or Gemini Notebook naming as fallback.
- Try the PDF URL first. After a confirmed import or processing failure, upload the PDF once into the same notebook. Allow download access or choose a file when prompted. Uncertain results and timeouts do not trigger another upload.
- Choose Audio Overviews, Video Overviews, reports, quizzes, flashcards, infographics, slide decks, mind maps, and data tables.
- Use the interface in English, Korean, Japanese, Spanish, French, German, or Brazilian Portuguese. It follows Chrome's language with English fallback. Artifact language is a separate setting for audio, video, reports, infographics, slide decks, and data tables.
- Add notebooks to a collection and follow progress after closing the popup. Stop Monitoring ends this workflow, but work already started in Gemini Notebook may continue.

Local uploads and direct downloads are limited to 40 MiB (41,943,040 bytes). Larger remote PDFs can use URL import. Upload larger local PDFs directly in Gemini Notebook.

Sign in to Gemini Notebook before starting. ScholarRelay uses your browser session and never asks for your Google password or verification code. No developer server, analytics, ads, or tracking. PDF website access is requested only when needed for a download.

ScholarRelay is independent and is not affiliated with or endorsed by Google. It uses unsupported web endpoints, so service changes may affect compatibility.

## 日本語

ScholarRelay（Scholar Relay）は PDF、arXiv の研究論文、ウェブページを Gemini Notebook（旧 NotebookLM）にインポートします。ノートブックの整理から音声解説や学習資料の生成まで、まとめて行えます。

- 現在のページの PDF またはローカルファイルをインポートします。論文タイトルは HTML メタデータやローカル PDF の限られた領域から取得します。見つからない場合は有用なファイル名、または Gemini Notebook の自動命名を使います。
- 最初に PDF の URL をインポートします。インポートや処理の失敗が確認された場合に限り、同じノートブックへ PDF を1回アップロードします。求められたらダウンロードを許可するかファイルを選択してください。結果が不明な場合やタイムアウト時には追加アップロードしません。
- 音声解説、動画解説、レポート、クイズ、フラッシュカード、インフォグラフィック、スライド資料、マインドマップ、データテーブルを選択できます。
- 画面は英語、韓国語、日本語、スペイン語、フランス語、ドイツ語、ブラジルポルトガル語に対応します。Chrome の言語に従い、未対応の言語では英語を使います。アーティファクトの言語は別設定で、音声、動画、レポート、インフォグラフィック、スライド資料、データテーブルに適用します。
- ノートブックをコレクションに追加し、ポップアップを閉じた後も進行状況を確認できます。モニタリングを停止するとこの処理は終了しますが、Gemini Notebook で開始済みの作業は続く場合があります。

ローカルアップロードと直接ダウンロードの上限は 40 MiB（41,943,040 バイト）です。それより大きいリモート PDF は URL でインポートできます。大きいローカル PDF は Gemini Notebook で直接アップロードしてください。

開始前に Gemini Notebook にログインしてください。ScholarRelay はブラウザのログインセッションを使用し、Google のパスワードや確認コードを要求しません。開発者サーバー、アクセス解析、広告、トラッキングはありません。PDF サイトへのアクセス権限はダウンロードに必要な場合のみ要求します。

ScholarRelay は独立した拡張機能であり、Google との提携や Google による推奨はありません。非公式のウェブエンドポイントを使用するため、サービス変更で互換性が失われる場合があります。
