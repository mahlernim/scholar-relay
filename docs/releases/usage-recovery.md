English

Show available compute usage in the existing subtitle and advisory artifact labels. Clear expired snapshots locally. A fresh post-failure read can add explicitly labeled compute-window reset context when the failed action lacks quota, without attributing every generation error to that meter.

한국어

서버가 요청한 재시도 대기 시간을 줄이지 않습니다. 작업 재시작 후에도 공유 조회 대기 시각과 준비 단계의 기한을 유지하며 기존 소스와 아티팩트 조회 제한 시간을 연장하지 않습니다. 결과가 불확실한 쓰기 요청은 반복하지 않습니다.

제공되는 연산 사용량을 기존 부제와 아티팩트 이름에 안내용으로 표시하고 만료된 정보는 로컬에서 숨깁니다. 생성 실패 후 새로 조회한 정보에서 해당 동작의 사용량 부족이 확인되면 연산 집계 구간 초기화 시각임을 명시합니다. 모든 생성 실패의 원인을 사용량 부족으로 단정하지 않습니다.

원인과 소스가 확인된 URL 연결 실패에 한해 페이지 본문 가져오기를 제공합니다. Google 전송 안내와 해당 사이트 접근 권한에 동의한 뒤 원래 탭에서 추출합니다. 기존 노트북에 한 번만 가져오고 실패한 소스는 유지하며 새 소스가 준비될 때까지 기다립니다. 동의 안내와 사용량 문구는 화면 언어 10개에 포함됩니다.
