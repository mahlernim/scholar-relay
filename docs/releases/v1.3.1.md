# ScholarRelay v1.3.1

## 한국어

- 팝업의 가져오기, 업로드, 권한 요청 문구를 간결하게 다듬고 아티팩트 용어를 유지했습니다.
- 아티팩트 언어를 공통 설정으로 옮겼습니다. 오디오를 꺼도 설정할 수 있으며 기존 저장값과 적용 범위는 그대로입니다.
- 팝업을 닫아도 작업이 계속됨을 안내하고, Stop Monitoring을 눌러도 Gemini Notebook에서 이미 시작된 작업은 계속될 수 있음을 설명합니다.
- 오류의 다음 행동을 먼저 안내하고 상세 정보는 펼쳐 볼 수 있게 했습니다. 결과가 불확실하면 다시 시작하기 전에 노트북을 확인하도록 안내합니다.
- 영어와 한국어 이름 및 소개를 PDF, arXiv 논문, 웹페이지 가져오기 중심으로 다듬고 Scholar Relay 표기를 추가했습니다. 스토어 검색 순위 개선을 보장하지는 않습니다.

## English

- Shorten popup import, upload, and permission wording while retaining artifact terminology.
- Move artifact language into shared settings. It remains accessible with Audio disabled and keeps the saved value and existing scope.
- Explain that work continues when the popup closes and that Stop Monitoring may leave work already started in Gemini Notebook running.
- Show the next action before expandable error details. Uncertain results direct users to inspect the notebook before starting again.
- Refine English and Korean names and descriptions around PDF, arXiv paper, and webpage import, including the spaced name Scholar Relay. Improved store ranking is not guaranteed.

URL-first import, same-notebook fallback, and the 40 MiB upload limit are unchanged.
URL 우선 가져오기, 같은 노트북으로의 업로드 전환, 40 MiB 업로드 한도는 그대로입니다.

Use the canonical ZIP for manual installation. The matching .sha256 asset contains its checksum. GitHub source archives are not the store package.
수동 설치에는 정식 ZIP을 사용하세요. 같은 이름의 .sha256 파일에 체크섬이 있습니다. GitHub 소스 압축 파일은 스토어 패키지와 다릅니다.
