# ScholarRelay v1.5.5

Patch release with session recovery, scheduled artifact handling, and Spanish for Latin America.

세션 복구, 예약된 결과물 처리와 라틴 아메리카 스페인어를 추가한 패치 릴리스입니다.

## English

- Distinguish Google sign-in from Notebook access restrictions and unrecognized session pages. Queued papers stay saved while you check access and explicitly retry the connection.
- Use one bounded read-only login check when app pages return without usable session information. Uncertain creation and upload requests are never automatically repeated.
- Preserve scheduled artifacts through polling and restart. Scheduled work is shown without an active generation animation. After 20 minutes of local monitoring, unresolved scheduled work stays in history with its notebook link and a Needs checking message, freeing the local queue slot.
- Add Spanish for Latin America, bringing the interface to 14 languages. Output language remains a separate setting.

## 한국어

- Google 로그인 필요, Notebook 접근 제한, 인식할 수 없는 세션 페이지를 구분합니다. 접근 상태를 확인하고 연결을 직접 재시도하는 동안 대기 중인 논문은 저장된 상태로 유지합니다.
- 앱 페이지에서 유효한 세션 정보를 찾을 수 없을 때 제한된 읽기 전용 로그인 확인을 한 번 수행합니다. 결과가 불확실한 생성과 업로드 요청은 자동으로 반복하지 않습니다.
- 예약된 결과물 상태를 조회와 재시작 후에도 보존하고 실제 생성 중 애니메이션과 구분합니다. 로컬 확인을 시작한 지 20분이 지나도 해결되지 않은 예약 작업은 노트북 링크와 확인 필요 안내를 기록에 남기고 로컬 대기열 자리를 비웁니다.
- 라틴 아메리카 스페인어를 추가하여 14개 화면 언어를 지원합니다. 결과물 언어는 별도로 설정합니다.

## Validation scope

333 automated tests, catalog checks and syntax validation passed. The isolated Chrome smoke covers all 14 languages at 320 and 360 pixels, saved session recovery, scheduled handoff, mixed generation limits, keyboard access, Arabic layout, and the exact 40 MiB transfer. Three Latin American Spanish store screenshots were visually inspected. [Sanitized live session evidence](v1.5.5-session-evidence.json) contains no tokens, cookies, account identifiers or full redirect URLs.

Session and scheduled-artifact regressions use controlled transport and persisted-state fixtures. A signed-in browser navigation from the app's `/login` endpoint returned to the app. In an isolated signed-out Chrome profile, both app roots returned HTTP 200 without usable tokens, then Chrome hid the login request's final cross-origin response. A partial redirect cannot distinguish sign-out from a signed-in session completing a sign-in handshake. That case retains SESSION_UNRECOGNIZED, as does a timeout. No new host or browser permission is added. Issue #110 retains the live detection limitation.

Scheduled-state support does not request deferred generation or claim a live scheduled artifact was created during validation. Existing immediate generation requests and wire formats are unchanged. Translation review is machine-assisted and follows official Spanish (Latin America) product terminology, without native-speaker certification.

실제 로그인된 브라우저에서 `/login` 이동은 앱으로 돌아왔습니다. 별도의 로그아웃 상태 Chrome에서는 두 앱 주소가 세션 정보 없는 HTTP 200을 반환한 뒤 최종 로그인 응답이 브라우저에 가려졌습니다. 중간 리디렉션이나 시간 초과만으로 로그아웃을 판단하지 않고 SESSION_UNRECOGNIZED를 유지합니다. 새 호스트나 브라우저 권한은 추가하지 않으며 #110의 실제 로그인 판별 제한은 후속 과제로 남깁니다. 예약 결과물은 모의 상태로 검증했으며 실제 예약 생성을 수행한 것은 아닙니다.

The manifest and package use patch version 1.5.5. The runtime ZIP contains 40 allowlisted files. Build, CI, package digest and store submission evidence are recorded with the published release. Store submission and public availability are separate states.
