# ScholarRelay v1.5.5

Patch release with session recovery, scheduled artifact handling, and Spanish for Latin America.

세션 복구, 예약된 결과물 처리와 라틴 아메리카 스페인어를 추가한 패치 릴리스입니다.

## English

- Distinguish Google sign-in from Notebook access restrictions and unrecognized session pages. Queued papers stay saved while you check access and explicitly retry the connection.
- Use one bounded read-only login check when app pages return without usable session information. Required access to `accounts.google.com` lets the check inspect the final sign-in URL and HTTP status without reading the sign-in page body or submitting passwords or verification codes. Uncertain creation and upload requests are never automatically repeated.
- Preserve scheduled artifacts through polling and restart. Scheduled work is shown without an active generation animation. After 20 minutes of local monitoring, unresolved scheduled work stays in history with its notebook link and a Needs checking message, freeing the local queue slot.
- Add Spanish for Latin America, bringing the interface to 14 languages. Output language remains a separate setting.

## 한국어

- Google 로그인 필요, Notebook 접근 제한, 인식할 수 없는 세션 페이지를 구분합니다. 접근 상태를 확인하고 연결을 직접 재시도하는 동안 대기 중인 논문은 저장된 상태로 유지합니다.
- 앱 페이지에서 유효한 세션 정보를 찾을 수 없을 때 제한된 읽기 전용 로그인 확인을 한 번 수행합니다. 필수 `accounts.google.com` 접근 권한으로 최종 로그인 URL과 HTTP 상태를 확인하며 로그인 페이지 본문을 읽거나 비밀번호와 인증 코드를 제출하지 않습니다. 결과가 불확실한 생성과 업로드 요청은 자동으로 반복하지 않습니다.
- 예약된 결과물 상태를 조회와 재시작 후에도 보존하고 실제 생성 중 애니메이션과 구분합니다. 로컬 확인을 시작한 지 20분이 지나도 해결되지 않은 예약 작업은 노트북 링크와 확인 필요 안내를 기록에 남기고 로컬 대기열 자리를 비웁니다.
- 라틴 아메리카 스페인어를 추가하여 14개 화면 언어를 지원합니다. 결과물 언어는 별도로 설정합니다.

## Validation scope

358 automated tests passed. All 14 locale catalogs match the 284 active messages, and syntax checks passed for 49 JavaScript files and 47 JSON files. The isolated Chrome smoke covers all 14 languages at 320 and 360 pixels, saved session recovery, scheduled handoff, mixed generation limits, keyboard access, Arabic layout, and the exact 40 MiB transfer. Three Latin American Spanish store screenshots were visually inspected. [Sanitized live session evidence](v1.5.5-session-evidence.json) contains no tokens, cookies, account identifiers, local profile paths or full redirect URLs.

Session and scheduled-artifact regressions use controlled transport and persisted-state fixtures. With the approved required `https://accounts.google.com/*` host permission, the candidate extension in a fresh signed-out Chrome 155 profile followed the bounded login check to the final `accounts.google.com/ServiceLogin` HTTP 401 response and returned AUTH_REQUIRED. Only a final HTTP 200 or 401 at a validated sign-in destination can establish that result. An arbitrary 401, unknown destination, blocked response, timeout or intermediate redirect cannot. Rate-limit, service and access failures keep their diagnostic priority.

A separate signed-in browser navigation from the app's `/login` endpoint returned to the app. This was navigation evidence, not a live run of the candidate extension in the user's signed-in profile. Valid signed-in app pages skip the probe in automated tests, and a probe that returns to the app remains unrecognized if normal discovery supplied no usable tokens. The host grant adds no `webRequest` or Cookies API permission. The extension does not read Accounts page bodies, inspect cookies through an API, submit credentials or select an account. See the [permission justification](v1.5.5-permissions.md).

Scheduled-state support does not request deferred generation or claim a live scheduled artifact was created during validation. Existing immediate generation requests and wire formats are unchanged. Translation review is machine-assisted and follows official Spanish (Latin America) product terminology, without native-speaker certification.

자동 테스트 358개, 14개 언어의 활성 문구 284개 일치 검사, JavaScript 파일 49개와 JSON 파일 47개의 구문 검사를 통과했습니다. 별도 프로필 Chrome 검증은 14개 언어의 320/360 픽셀 화면, 저장된 세션 복구, 예약 작업 인계, 동시 생성 제한, 키보드 조작, 아랍어 레이아웃과 정확히 40 MiB인 전송을 다룹니다. 라틴 아메리카 스페인어 스토어 스크린샷 3개를 확인했습니다. 공개한 실제 세션 근거에는 토큰, 쿠키, 계정 식별자, 로컬 프로필 경로나 전체 리디렉션 URL이 없습니다.

승인된 필수 `https://accounts.google.com/*` 권한을 적용한 후보 확장 프로그램을 새 로그아웃 상태 Chrome 155 프로필에서 검증했습니다. 제한된 로그인 확인이 최종 `accounts.google.com/ServiceLogin` HTTP 401 응답에 도달하여 AUTH_REQUIRED를 반환했습니다. 검증된 최종 로그인 주소의 HTTP 200 또는 401만 로그인 필요로 판단합니다. 임의의 401, 알 수 없는 주소, 차단된 응답, 시간 초과나 중간 리디렉션만으로 판단하지 않으며 사용량 제한, 서비스 장애와 접근 제한의 우선순위를 유지합니다.

별도로 로그인된 브라우저에서 `/login` 이동이 앱으로 돌아오는 것을 확인했습니다. 이는 브라우저 이동 근거이며 사용자의 로그인된 프로필에서 후보 확장 프로그램을 실행한 검증은 아닙니다. 자동 테스트에서는 유효한 로그인 세션이 있으면 추가 확인을 생략하고, 정상 탐색에서 토큰을 얻지 못한 채 확인 요청이 앱으로 돌아오면 알 수 없는 세션으로 유지합니다. `webRequest`나 Cookies API 권한은 추가하지 않았으며 Accounts 본문 읽기, API를 통한 쿠키 조회, 인증 정보 제출과 계정 선택을 하지 않습니다. 예약 결과물은 모의 상태로 검증했으며 실제 예약 생성을 요청한 것은 아닙니다. 기존 즉시 생성 요청 형식은 유지하며 번역은 공식 용어를 참고한 기계 보조 검토로, 원어민 인증 검수는 아닙니다.

The manifest and package use patch version 1.5.5. The runtime ZIP contains 40 allowlisted files. Build, CI, package digest and store submission evidence are recorded with the published release. Store submission and public availability are separate states.
