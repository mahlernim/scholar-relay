# ScholarRelay v1.4.0

## English

- Add multiple papers to a persistent queue. Each job keeps its own notebook, artifact choices, language, prompts, and notification preferences.
- See when a paper is saved, when Chrome is still needed, and when Gemini Notebook has accepted the requests and can continue independently.
- Prepare one paper at a time while up to three notebooks generate artifacts. Pause new starts or stop one job without interrupting the others.
- Save local PDFs before confirming a queued job. The limits are 40 MiB per file, 100 MiB combined, and 20 unfinished jobs. Saved files are removed after upload, failure, or job removal.
- Fix notebook ID parsing, unknown source readiness, premature media completion, and misleading failure messages after uncertain generation responses. Keep the original diagnostics and never blindly repeat a write.
- Bound stalled authentication, reads, downloads, and uploads so other queued work can continue. Update all seven interface languages and store listings.

## 한국어

- 여러 논문을 유지되는 대기열에 추가할 수 있습니다. 각 작업은 별도 노트북과 추가 당시의 아티팩트 선택, 언어, 맞춤 안내, 알림 설정을 유지합니다.
- 논문이 저장된 시점, Chrome을 계속 실행해야 하는 단계, Gemini Notebook이 요청을 접수하여 독립적으로 생성할 수 있는 시점을 안내합니다.
- 논문을 하나씩 준비하면서 최대 3개 노트북에서 아티팩트를 생성합니다. 새 작업 시작을 일시정지하거나 다른 논문에 영향을 주지 않고 개별 작업을 중지할 수 있습니다.
- 로컬 PDF를 저장한 뒤 대기열 추가를 확인합니다. 파일당 40 MiB, 합계 100 MiB, 미완료 작업 20개로 제한합니다. 업로드, 실패 또는 작업 제거 후 저장 파일을 삭제합니다.
- 노트북 ID 해석, 확인되지 않은 소스 준비 상태, 미디어의 조기 완료 표시, 결과가 불확실한 생성 요청의 잘못된 실패 안내를 수정합니다. 원래 진단 정보를 유지하며 쓰기 요청을 무작정 반복하지 않습니다.
- 인증, 조회, 다운로드, 업로드의 대기 시간을 제한하여 멈춘 연결이 다른 작업을 계속 막지 않도록 합니다. 7개 화면 언어와 스토어 설명을 갱신합니다.
