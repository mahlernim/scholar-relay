# ScholarRelay v1.5.1

## English

- Add Traditional Chinese as the tenth interface language. Product labels follow the Traditional Chinese Gemini Notebook interface.
- Treat an artifact status response that carries an error code as a failed read instead of an empty list. Sign-in failures refresh the session once, other failures keep waiting and are logged, and unused-notebook cleanup does not proceed on an unreadable status.

## 한국어

- 열 번째 화면 언어로 중국어 번체를 추가합니다. 제품 용어는 중국어 번체 Gemini Notebook 화면을 따릅니다.
- 아티팩트 상태 응답에 오류 코드가 포함되면 빈 목록이 아닌 읽기 실패로 처리합니다. 로그인 실패는 세션을 한 번 갱신하고, 그 밖의 실패는 기록한 뒤 계속 기다리며, 상태를 읽지 못하면 사용하지 않는 노트북을 정리하지 않습니다.

## 繁體中文

- 新增繁體中文，成為第十種介面語言。產品用語與繁體中文版 Gemini Notebook 介面一致。
- 工作室內容狀態回應若帶有錯誤代碼，現在會視為讀取失敗，而不是空白清單。登入失敗時會重新整理工作階段一次，其他失敗會記錄下來並繼續等待；無法讀取狀態時，不會清理未使用的筆記本。

## Validation and release state

Traditional Chinese is machine-assisted and has not received independent native-speaker review. Product labels were read from the signed-in interface at `hl=zh-TW`. Store listing text and screenshots are dashboard operations and are prepared in `v1.5.1-store-listing.md`.
