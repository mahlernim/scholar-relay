# ScholarRelay v1.5.6

## English

- Import the current webpage even when one linked paper is detected. An optional setting saves up to 200 kB of page text locally when starting a webpage job and uploads it once only after a confirmed URL import failure. The setting is off by default. Saved text is removed when no longer needed.
- Let slow PDF downloads continue while data arrives, with a 25-second stall limit, a ten-minute ceiling, and the existing 40 MiB size and PDF signature checks.
- Download a citation PDF directly when the article explicitly declares restricted access. After a publisher returns HTTP 401 or 403, retry once from the unchanged original article tab when it is on the same origin. Cancellation stops the transfer, and loss of the worker expires the page transfer's short lease.
- Check newly added sources sooner without polling unrelated notebooks. Preserve source identities, cancellation, restart recovery, and unknown request outcomes.

## 한국어

- 연결된 논문이 하나만 감지되어도 현재 웹페이지를 가져올 수 있습니다. 선택 설정을 켜면 웹페이지 작업을 시작할 때 본문을 최대 200 kB까지 로컬에 저장하고, URL 가져오기 실패가 확인된 경우에만 한 번 업로드합니다. 기본값은 꺼짐이며 필요 없어진 본문은 삭제합니다.
- 데이터가 계속 도착하면 느린 PDF 다운로드를 유지합니다. 25초 동안 데이터가 없거나 전체 10분이 지나면 중단하며, 기존 40 MiB 크기 제한과 PDF 서명 검사를 유지합니다.
- 논문에 접근 제한이 명시되어 있으면 인용 메타데이터의 PDF를 직접 내려받습니다. 출판사가 HTTP 401 또는 403을 반환하면 같은 출처의 원래 논문 탭이 그대로 열려 있을 때 한 번 재시도합니다. 작업 취소 시 전송을 중단하고, 작업자가 사라지면 짧은 유지 확인 시간이 지난 뒤 페이지 전송도 중단합니다.
- 새로 추가된 소스를 더 일찍 확인하되 다른 노트북을 불필요하게 조회하지 않습니다. 소스 식별자, 취소, 재시작 복구와 결과가 불확실한 요청의 보호 동작을 유지합니다.

## Validation

The release includes the contributor's five PRs and focused corrections for uncertain source creation, source-timeout reconciliation, scoped early checks, and page-download cancellation. Automated tests use controlled transport. Publisher-specific signed-in downloads reported in the original PRs were not independently repeated for this release. Chrome smoke checks cover fourteen languages at 320 and 360 pixels, the webpage control and fallback setting, restart, cancellation, and the existing exact 40 MiB transfer.

No new permissions, developer telemetry, or generation request formats are introduced. Store descriptions disclose temporary local storage for the optional page-text fallback. GitHub publication, store submission, and public store availability are recorded separately.
