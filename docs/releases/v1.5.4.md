# ScholarRelay v1.5.4

Draft patch release. Not published or submitted to the Chrome Web Store.

## English

- Add Dutch interface text and notifications, bringing support to 13 languages. Output language remains a separate setting.
- Correct Simplified Chinese product terms and workflow guidance, with refreshed screenshots.
- Show available artifact duration and counts in existing details rows. Unknown metadata stays hidden.
- Show the selected audio length in the start summary.
- Remove redundant polling and elapsed-minute text while keeping the live queue clock.

## 한국어

- 네덜란드어 화면과 알림을 추가하여 13개 언어를 지원합니다. 결과물 언어는 별도로 설정합니다.
- 중국어 간체 제품 용어와 작업 안내를 수정하고 스크린샷을 갱신했습니다.
- 제공되는 결과물 재생 시간과 개수를 기존 상세 행에 표시합니다. 확인되지 않은 정보는 숨깁니다.
- 시작 전 요약에 선택한 오디오 길이를 표시합니다.
- 중복된 조회 주기와 경과 분 안내를 제거하고 대기열의 실시간 시계는 유지합니다.

## Validation

290 automated tests, catalog checks, and the isolated Chrome smoke passed. Browser coverage includes all 13 languages at 320 and 360 pixels, saved audio length, queue and recovery states, keyboard checks, Arabic layout, and the exact 40 MiB transfer. Dutch and Simplified Chinese store screenshots were visually inspected. Translation review is machine-assisted, not native-speaker certification.

Live artifact evidence confirms audio duration and source count. Video duration and slide count have validated synthetic fixtures but no authenticated sample in this release investigation. Missing or malformed optional fields stay unknown and do not affect readiness. The reported short Long audio was confirmed to have been requested as Default. No audio wire-format fix is included.

The manifest and package use patch version 1.5.4. The runtime ZIP contains 39 allowlisted files. Publication and store submission remain separate future actions.
