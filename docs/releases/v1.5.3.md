# ScholarRelay v1.5.3

## English

- Add Arabic as the twelfth interface language, with localized notifications, store materials, and right-to-left layouts. Notebook titles, URLs, custom prompts, and output-language choices keep their original values.
- Show Generating only for known work in progress. Uncertain outcomes and confirmed failures show Needs checking with specific guidance. Ready means the results are complete.
- Preserve uncertain mutation outcomes after authentication rejection without replaying writes. Refresh the shared session for later calls and keep read recovery bounded.
- Surface explicit mind-map save and notebook deletion errors. Preserve accepted note IDs across restart and retain notebook links when deletion fails or remains uncertain.

## 한국어

- 열두 번째 화면 언어로 아랍어를 추가하고 알림, 스토어 자료와 오른쪽에서 왼쪽으로 읽는 레이아웃을 제공합니다. 노트북 제목, URL, 사용자 프롬프트와 결과물 언어 설정은 원래 값을 유지합니다.
- 진행 중인 작업이 확인된 경우에만 생성 중으로 표시합니다. 결과 미확인과 명시적 실패는 구체적인 안내와 함께 확인 필요로 표시하며, 결과가 모두 완료된 경우에만 준비 완료로 표시합니다.
- 인증 거부 후에도 결과가 불확실한 변경 요청을 다시 보내지 않습니다. 이후 요청을 위해 공유 세션을 갱신하고 읽기 요청의 복구 횟수를 제한합니다.
- 마인드맵 저장과 노트북 삭제의 명시적 오류를 표시합니다. 접수된 노트 ID는 재시작 후에도 유지하고 삭제 실패나 결과 미확인 시 노트북 링크를 보존합니다.

## Validation

Arabic is a machine-assisted editorial translation with a separate semantic review and official Arabic Help terminology checks. This is not native-speaker certification. Automated catalog and browser fixtures cover placeholders, right-to-left layout, and workflow behavior without creating live Google content. Store submission status is recorded separately from publication.

Local validation passed 283 unit tests, catalog generation checks, and the full isolated Chrome smoke. Browser checks cover all twelve locales, Arabic at 320 and 360 pixels, queue and recovery states, and the exact 40 MiB transfer. The Arabic store images were visually inspected as 1280 × 800 RGB PNGs. Exact-head and merged-main CI are required before release.

아랍어는 기계 지원 번역이며 별도의 의미 검토와 공식 도움말 용어 확인을 거쳤습니다. 원어민 검수는 아닙니다. 자동 테스트 283개와 번역 카탈로그 검사, 격리된 Chrome 전체 검증을 통과했습니다. 12개 언어, 아랍어 320/360 픽셀 화면, 대기열과 복구 상태, 정확한 40 MiB 전송을 확인했고 1280 × 800 RGB PNG 스토어 이미지를 시각적으로 검토했습니다. 실제 Google 콘텐츠를 생성한 검증은 아닙니다. 릴리스 전 정확한 PR 커밋과 병합된 main의 CI 통과를 확인하며, 스토어 제출 상태와 실제 공개는 별도로 기록합니다.
