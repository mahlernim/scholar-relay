# Dutch catalog review

Reviewed October 16, 2026 against the 279 active English keys after PR #111. The catalog was translated and reviewed by the release author for source meaning, placeholders, uncertainty, cancellation and keep-Chrome-open guidance. This is machine-assisted editorial review without native-speaker certification or independent model consensus.

Google's Dutch Help uses notebook, bron, audio-overzicht, video-overzicht, flashcards, toetsen and diapresentaties. References checked on the review date include [notebook creation](https://support.google.com/gemininotebook/answer/16206563?hl=nl) and [flashcards and tests](https://support.google.com/gemininotebook/answer/16958963?hl=nl). Extension-specific labels such as Artikelwachtrij and verzameling are editorial choices. Other format names are descriptive translations and are not claimed to be exact signed-in Google labels.

Every source key has a Dutch value. Numbered placeholders retain their roles and user text remains unchanged. Standaard is used for the Default length, Lang for Long and Gemiddeld for Medium difficulty. Failed requests remain distinct from unknown outcomes. Closing Chrome is permitted only after remote generation has started.

The generator checks completeness, placeholders, collisions and store metadata limits. The real popup smoke checks Dutch alongside the other twelve locales, including queue, recovery, saved settings, literal user prompts and 320/360-pixel layouts. The three Dutch store screenshots were visually inspected at 1280 by 800 pixels. The output-language selector remains unchanged.
