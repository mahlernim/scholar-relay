# Latin American Spanish for v1.5.5

The new `es_419` source catalog was adapted from the English source keys using the existing `es` translations as a baseline on October 22, 2026. The existing Spanish catalog remains unchanged apart from translations for newly introduced shared recovery states. Interface translation does not alter output-language settings, prompts, IDs, or API values.

## Terminology

Google's es-419 Help explicitly labels the Studio controls Resumen en audio, Resumen en video, Tarjetas, and Cuestionarios. The audio format Critique is Opinión. These labels informed the new catalog. The singular Quiz label stays Cuestionario to match the extension's individual artifact row. Brief remains Resumen because the same source key is shared by audio and video controls. Other extension labels are editorial translations.

- [Audio Help](https://support.google.com/gemininotebook/answer/16212820?hl=es-419)
- [Video Help](https://support.google.com/gemininotebook/answer/16454555?hl=es-419)
- [Study tools Help](https://support.google.com/gemininotebook/answer/16958963?hl=es-419)
- [Chrome supported locales and fallback](https://developer.chrome.com/docs/extensions/reference/api/i18n)

Regional choices include agregar, video, íconos, and enfócate. Safety guidance preserves uncertain outcomes, sign-in and access distinctions, explicit deletion, source ownership, and the absence of automatic mutation retries. Scheduled means accepted for later server generation, not active generation or completion.

## Validation limits

This is machine-assisted editorial translation with official Help terminology checks. It is not independent native-speaker review or a signed-in es-419 interface inspection. The catalog generator checks completeness and placeholder equality. Existing locale tests and browser fixtures exercise the new catalog, with the release validation results recorded separately.
